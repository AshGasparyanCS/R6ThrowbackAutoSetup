# R6ThrowbackAutoSetup
Automated setup tool for Old Siege (R6 Throwback).

**How to use:**
1. Download R6ThrowbackSetup.exe below
2. Run it - (if Windows shows a SmartScreen warning, click More info → Run anyway)
3. Fill in your OLD R6 folder, in-game name, Steam username, and pick your season
4. Click START SETUP and follow the prompts

**Requirements:** 

- Windows 10/11 64-bit
- Steam account
- ~50GB free space per season
